1. Preserve the Day 27 research contract and source-separated series. Never claim real-time meter access or production validation.
2. Keep all API routes consistent with the checked-in FastAPI backend. No fabricated endpoints, timestamps, metrics, or example predictions represented as measurements.
3. Do not turn held-out snapshots into future forecast claims. Report the actual dataset units and chronological validation limitations.
4. Require ordered, complete, numeric, past-observable features for inference. Disable inference when model/schema absent.
5. Use TypeScript strict checks, accessible semantic inputs, mobile responsiveness, loading/empty/error states, and meaningful labels.
6. Keep secrets out of frontend environment; only expose VITE_API_BASE_URL.
7. Update README and docs/id counterparts when behavior/claims change. Never abbreviate the Indonesian translation of a full English document.
8. Run npm run build before proposing changes; do not claim running frontend tests or live backend access without actual evidence.
9. Never push dataset archives, private raw data, local credentials, or unreviewed model binaries.
